Какие группы проверяем?

Можно выбрать две или больше групп. Все участники отмечаются через одну камеру, итоги сохраняются по каждой группе. Пустые группы станут доступны после добавления людей.

Новая группа

При регистрации человека выберите эту группу. Уже добавленных людей можно перевести кнопкой «Группа» в списке.

Изменить группу

Изменение применяется к новым проверкам. Состав текущей проверки и история сохраняются.
